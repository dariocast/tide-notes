# Security Policy

## Supported Versions

Only the latest release of Tide receives security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.3.x   | :white_check_mark: |
| < 1.3.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Tide, please do **not** disclose it publicly via GitHub Issues.

Instead, please report security issues privately through [GitHub Security Advisories](https://github.com/dariocast/tide-notes/security/advisories/new) or by reaching out to the maintainers.

Please include:
- A description of the issue.
- Steps or proof of concept to reproduce.
- Any suggested fixes or mitigations.

We will review the report promptly and coordinate a fix and advisory.
