# Tide MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Tide as a polished offline Flutter app for iOS, Android, and macOS with append, inline edit, position-based sinking, rescue, and undo.

**Architecture:** Clean Architecture organized layer-first. `flutter_bloc` owns business/async state, domain stays pure Dart, and a Drift repository persists the single reactive stream locally behind a domain interface.

**Tech Stack:** Flutter 3.41.5, Dart 3.11.3, Material 3, flutter_bloc, equatable, Drift/SQLite, drift_flutter, uuid, build_runner, drift_dev, bloc_test, mocktail, integration_test.

```dart
// lib/domain/repositories/note_repository.dart
import '../entities/note.dart';
import '../entities/rescue_receipt.dart';

abstract interface class NoteRepository {
  Stream<List<Note>> watchNotes();
  Future<void> createNote(Note note);
  Future<void> updateContent(String id, String content, DateTime updatedAt);
  Future<RescueReceipt?> rescue(String id, DateTime surfacedAt);
  Future<void> undoRescue(RescueReceipt receipt);
}
```

`Note` is immutable, uses value equality, and contains exactly `id`, `content`, `createdAt`, `updatedAt`, `surfacedAt`, `rescueCount`. `RescueReceipt` contains `noteId`, `previousSurfacedAt`, `previousRescueCount`, `rescuedSurfacedAt`.

Use constructor-injected functions for deterministic tests:

```dart
typedef Now = DateTime Function();
typedef NewId = String Function();
```

`AppendNote` receives `NoteRepository`, `Now`, `NewId`; normalizes via:

```dart
String normalizeContent(String input) {
  final normalized = input.replaceFirst(RegExp(r'\s+$'), '');
  if (normalized.trim().isEmpty) throw ArgumentError.value(input, 'content');
  return normalized;
}
```

`EditNote` receives repository and `Now`; it validates with the same normalizer. `RescueNote` receives repository and `Now`. `WatchNotes` and `UndoRescue` delegate directly.

// essential schema in tide_database.dart
class NoteRecords extends Table {
  TextColumn get id => text()();
  TextColumn get content => text()();
  DateTimeColumn get createdAt => dateTime()();
  DateTimeColumn get updatedAt => dateTime()();
  DateTimeColumn get surfacedAt => dateTime()();
  IntColumn get rescueCount => integer().withDefault(const Constant(0))();
  @override Set<Column<Object>> get primaryKey => {id};
}

@DriftDatabase(tables: [NoteRecords])
class TideDatabase extends _$TideDatabase {
  TideDatabase() : super(driftDatabase(name: 'tide'));
  TideDatabase.forTesting(super.executor);
  @override int get schemaVersion => 1;
}
```

Queries must sort with `OrderingTerm.desc(noteRecords.surfacedAt)` then `OrderingTerm.desc(noteRecords.id)`. Rescue and undo run inside `transaction`. Undo updates only a row matching both receipt note ID and rescued timestamp, preventing a stale snackbar from reverting a later rescue.

`NoteModel` provides `fromRecord`, `toEntity`, and companion conversion. Domain entities never import Drift.

  WidgetsFlutterBinding.ensureInitialized();

}

class TideBootstrap extends StatefulWidget {
  const TideBootstrap({super.key});
  @override
  State<TideBootstrap> createState() => _TideBootstrapState();
}

class _TideBootstrapState extends State<TideBootstrap> {
  late final TideDatabase database = TideDatabase();
  late final NoteRepository repository = LocalNoteRepository(database);
  final uuid = const Uuid();

  @override
  Widget build(BuildContext context) => RepositoryProvider<NoteRepository>.value(
        value: repository,
        child: BlocProvider(
          create: (_) => TideBloc(
            watchNotes: WatchNotes(repository),
            appendNote: AppendNote(repository, now: DateTime.now, newId: uuid.v4),
            editNote: EditNote(repository, now: DateTime.now),
            rescueNote: RescueNote(repository, now: DateTime.now),
            undoRescue: UndoRescue(repository),
          )..add(const TideStarted()),
          child: const TideApp(home: TidePage()),
        ),
      );

  @override
  void dispose() {
    database.close();
    super.dispose();
  }
}
```

Keep `TideApp.home` required so tests and composition remain explicit. Do not create global singletons.
